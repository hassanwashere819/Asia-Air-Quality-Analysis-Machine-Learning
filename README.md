# Asia-Air-Quality-Analysis-Machine-Learning
This project analyzes air-quality data from 2,164 cities across Asia to identify pollution patterns, differences between locations, and important factors associated with air-quality levels.

I cleaned and explored the dataset, handled missing values using multiple imputation techniques, and investigated pollution distributions, correlations, seasonal patterns, and outliers. I then used PCA, t-SNE, and UMAP for dimensionality reduction and K-Means and DBSCAN to identify groups of cities with similar pollution characteristics.

For machine learning, I performed feature selection using correlation analysis, mutual information, VIF, and RFE, followed by training and comparison of Logistic Regression, SVM, Random Forest, XGBoost, and CatBoost models. Model performance was evaluated using Stratified 5-Fold Cross-Validation, Accuracy, Precision, Recall, F1-score, and ROC-AUC.
